# Engflow Implement

[SKILL.md](SKILL.md) is the authoritative contract.

Implement turns the agreed Spec, Design and Plan into working, verified code.
It can refine near-term work as implementation reveals details. A separate task
record is optional.

Examples:
- "Implement this plan, run the relevant tests and review the change."
- "Resume the work without disturbing my uncommitted changes."
- "The current data model is not working; explain the evidence and ask me before
  changing the technical direction."

Use the [review method](references/review-core.md) and [Git scope guidance](references/scope.md).
For substantial or resumed work, see [execution continuity](references/continuity.md).
