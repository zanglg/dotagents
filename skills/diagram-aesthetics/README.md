# Diagram Aesthetics

User guide; [SKILL.md](SKILL.md) is the authoritative agent contract.

## Purpose

Give technical diagrams and scientific charts coherent color, typography,
line weight and spacing while preserving notation and meaning.

## Examples

- "Make these diagrams visually consistent."
- "Review this chart for final-size readability and visual hierarchy."

## Inputs and outputs

Provide the figure or editable source, output size and any theme or notation
constraints. Receive styling guidance, visual findings or authorized asset changes.
This skill supplies no renderer or drawing-tool tutorial.

## Installation and collaboration

Copy this whole folder into your host's skill directory, preserving
supporting files. No other Skill or helper runtime is required.

## Validation and references

See the [default theme](references/default-theme.md). Check final-size
readability, contrast, font fallback and consistency. Visual inspection does not
prove formal accessibility conformance.
