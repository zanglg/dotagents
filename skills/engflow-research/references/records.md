# Research record convention

Research returns evidence to its caller or conversation by default. A report
is persisted only on an explicit save request with adequate write authority;
an investigation-only helper cannot save a report merely because it is a
subagent. Source inspection does not authorize execution or project edits.

Use the user's destination or established project convention; otherwise
save to `docs/research/NNN-short-name.md`. Number new records above existing
Research identities, starting at `001` with at least three digits. Keep
identities stable, do not fill gaps, renumber or overwrite collisions, and
check the target before writing. Research numbering is independent of feature
and PoC numbering. A preview does not create files or reserve numbers.

Reuse the appropriate existing record for a continuing question, preserving
useful history and distinguishing historical from new evidence. Saving results
does not rerun the investigation or make old observations current. Refer to
existing feature/Design sources without creating them or changing navigation.
Use the [optional report outline](../assets/research.md) only when helpful.

Report the actual saved path, evidence, provenance and limitations. A caller
may integrate accepted findings into its separately authorized records, but
Research itself grants neither that write nor design approval.
