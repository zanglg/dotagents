# Research records

Return findings to the caller or in conversation by default. Save only on
explicit request and within write authority. The Research task owner handles
authorized report writes; investigation-only helpers return evidence rather
than saving it. Ownership depends on assigned scope, not on whether the host
runs the agent as a subagent.

Reuse an existing record for a continuing question. Honor the supplied path
or project convention; otherwise use `docs/research/NNN-short-name.md`.
For a new record, allocate the next number above existing Research records,
starting at `001` with at least three digits. Do not fill gaps, renumber or
overwrite a collision; recheck before writing. Research numbering is
independent of features and PoCs. Preview creates no files or reserved numbers.

Preserve useful history and distinguish prior evidence from new observations.
Saving existing findings does not rerun the investigation. Reference related
feature records without creating them or changing navigation. Use the
[optional outline](../assets/research.md) when helpful. Report the actual
saved path and evidence limits.
