# Optional read-only collaboration

Delegate a bounded question when independent context or focused investigation
offers meaningful benefit. Otherwise assess directly.

Give the helper enough context to reason correctly: the question, essential
constraints and decisions, relevant source state, evidence access and authority
limits. Do not assume shared files or independent context the host cannot provide.

Both parent and helpers remain read-only. Do not write files, mutate project or
external state, or run checks with such side effects. Helpers do not delegate
further. An assignment grants no authority beyond the governing coordinator's
restrictions.

A useful return connects recommendations to evidence and expected maintenance
benefits, preserving material tradeoffs, counterevidence and uncertainty. Let the
question determine its structure and depth.

The parent remains responsible for the assessment: verify consequential claims,
reconcile conflicting evidence and recheck findings affected by source changes.
Disclose unresolved limits rather than inventing access, observations or results.
Collaboration does not authorize reports, progress records or handoff files.
