# 技术图表配色规范与色值

本参考保留原有中性色、七组候选色谱及组件配色，补充组合规则、文字对比度和状态叠加要求。具体色值是可执行的默认值，不是禁止调整的品牌色。调整必须有信息表达或可读性理由，并同步更新同一系列图示。线宽、箭头、排版、路由和线型含义见 [几何、排版与连线规范](visual-style.md)。

## 1. 配色原则

使用克制、协调、低色度的配色；白色和接近中性的表面占主体。分类浅填充非常浅；主题核心填充可以适当降低明度、增强色相倾向，以免融入父容器。较强颜色优先用于边框、协调的文字色组、连接线和小面积数据标记。

- 蓝色是默认主色，可表达核心内容、主要数据或主题强调，不再专属于激活状态。
- 单一主色足够时不增加色相；同色系不足以辨识类别时，允许增加其他色系。
- 优先考虑同色系或相近色系的协调关系，但不限定必须使用蓝紫红，也不排除其他颜色。
- 不同色系也可以通过统一的明度、色度、面积和组件用法形成协调感。
- 同等类别尽量保持相近视觉重量；有意强调时才增加明暗、色度或面积差异。
- 分类色只在当前上下文中定义含义，不永久绑定对象类型；同图及连续图示必须保持映射一致。
- 不为了低饱和度而牺牲文字、数据和状态辨识。协调不等于颜色全部接近，克制不等于低对比。

不使用未指定颜色空间的“饱和度低于某百分比”作为硬约束。以本色板为基准；扩展时可用 OKLCH 辅助控制明度与色度，并检查 sRGB 等目标输出色域及实际对比度。

## 2. 中性色基础

| 角色 | 颜色 |
|---|---|
| 画布 | `#FFFFFF` |
| 表面 1 | `#F8FAFB` |
| 表面 2 | `#F3F5F6` |
| 表面 3 | `#ECEFF1` |
| 柔和灰色填充 | `#F1F3F5` |
| 普通边框 | `#CBD2D8` |
| 强边框 | `#A9B2BA` |
| 关键边界 | `#7C8791` |
| 主文字 | `#2B3137` |
| 柔和主文字 | `#3F474E` |
| 次级文字 | `#626D76` |
| 辅助 / 弱化文字 | `#606D76` |
| 禁用控件文字 | `#9AA2A9` |
| 普通线条 | `#6D7881` |
| 弱线条 | `#8B949C` |

默认表面层级：`#FFFFFF -> #F8FAFB -> #F3F5F6 -> #ECEFF1`。

这些表面色是嵌套背景的候选，不要求全部同时使用，也不宜作为相邻数据类别的唯一差异。避免无意义地从白色背景跳到大面积深灰；关键数据或局部重点可以使用深色。

普通边框与强边框适合轻量容器，但不保证达到关键图形边界所需对比度。若必须依靠轮廓辨认对象，优先使用关键边界，并对实际背景验证；深层表面上可能需要进一步加深。

原弱化文字 `#7C868E` 不再用于普通信息文字。辅助文字与次级文字刻意保持接近的可读性，通过位置、字重和间距表达层级，而非继续淡化。禁用控件文字仅适用于真正禁用的控件，不能用于静态图中仍需阅读的信息。

## 3. 卡片颜色

### 3.1 中性卡片

| 卡片类型 | 填充 | 边框 | 主文字 | 次级文字 |
|---|---|---|---|---|
| 默认 | `#FFFFFF` | `#CBD2D8` | `#2B3137` | `#626D76` |
| 次级 | `#F8FAFB` | `#CBD2D8` | `#2B3137` | `#626D76` |
| 弱化 | `#F3F5F6` | `#D1D7DC` | `#3F474E` | `#606D76` |

普通卡片保持中性；主题核心、分类或状态需要时才引入颜色。弱化卡片通过位置、边框重量和减少强调表达次要性，不通过降低整体透明度实现。

需要清晰轮廓时，将表中的柔和边框替换为关键边界或对应色系的图形强调色，并验证实际对比度。若默认主文字在浅色设计中显得过黑，可以将同组中性卡片的标题和正文统一改用柔和主文字 `#3F474E`，不要逐句随机改变色调。

### 3.2 主题核心卡片

分类浅填充负责轻量分组，不保证足以突出主题核心。核心卡片使用更明确但仍柔和的同色系填充，并配套设计整张卡片的文字颜色。

默认蓝色核心卡片：

| 角色 | 颜色 |
|---|---|
| 填充 | `#DFE9F2` |
| 描边 | `#587795` |
| 标题与正文 | `#465E73` |
| 辅助文字 | `#50677B` |

标题与正文使用同一个蓝灰色，通过字号和字重区分层级；辅助文字仅略微调整明度，不切换为另一种色调。主文字与填充对比度约为 5.49:1，辅助文字约为 4.79:1，描边约为 3.80:1。填充变深后不能直接沿用原次级文字 `#626D76`，它在此背景上只有约 4.30:1。

此组合是主题强调的默认扩展，不替换七组基础色谱，也不是选中状态。其他主题色可按同样角色构造配套色组，并重新验证。

### 3.3 父子容器层级

- 在实际父容器背景上评估卡片，而不是只在白底上看色板。
- 核心卡片不能因填充接近父容器，反而比普通白色卡片更不显眼。
- 例如父容器 `#F8FAFB` 与分类蓝填充 `#F1F4F6` 的亮度对比度仅约 1.06:1，不适合仅靠这点差异突出核心；保留父容器，优先使用明确的核心填充和描边。
- 主题核心仍不突出时，可增加窄色条或结构标记，不优先给父容器染色或引入无关色相。
- 背景间对比度用于诊断，不设统一的 3:1 门槛；最终应结合色相、边界、面积及非颜色标记判断视觉层级。

## 4. 候选色谱与组合

### 4.1 七组基础色

保留原有浅填充与柔和边框；把原“强调色 / 文字”拆成图形强调色和更深的彩色文字，避免将适合描边的颜色直接用于小字。

| 色系 | 浅填充 | 柔和边框 | 图形强调色 | 彩色文字 |
|---|---|---|---|---|
| 蓝色 | `#F1F4F6` | `#C4CED6` | `#627789` | `#50677B` |
| 绿色 | `#F1F5F3` | `#C5D0CA` | `#687C71` | `#52685B` |
| 沙色 | `#F6F3EF` | `#D4CCC3` | `#7B7064` | `#6B6054` |
| 紫色 | `#F4F2F5` | `#CEC8D1` | `#756C79` | `#655A6C` |
| 青色 | `#F0F5F4` | `#C1CFCD` | `#647A77` | `#506965` |
| 石板色 | `#F1F3F5` | `#C7CDD3` | `#667481` | `#566573` |
| 琥珀色 | `#F7F5EF` | `#D5D0C1` | `#7D7561` | `#6D644F` |

这是一组候选色库，不是七类数据必须同时使用的分类色板。浅填充之间差异很小，需要标题、标签、位置或描边辅助区分。

### 4.2 组合方式

1. **中性色加一个主色。** 无明确主题约束时默认蓝色；有主题、出版规范或领域惯例时可选择其他主色。
2. **同色系层级。** 用浅填充、较深描边、深色文字建立统一层次。这是用途层级，不自动表示数量或不同类别。
3. **协调的多色系。** 分类需要时增加色相，通常先使用 2-4 个色系，不设最低数量。优先尝试相近色系，但以可辨识性为准；没有固定扩展顺序。
4. **更明显的差异。** 对照关系、类别数量或领域语义确有需要时，可以扩大色相差异。通过明度、色度和使用面积保持整体协调，不默认采用鲜艳的互补色对撞。

蓝与石板、绿与青、沙与琥珀各自很接近，可以作为不同主题下的替代选择；若共同表示不同类别，不能仅依靠浅填充区分。

同一图中普通分类与错误同时存在时，本默认色库不新增装饰性红色分类。若外部既定色板含红色类别，应通过明确的状态标记消除混淆，必要时调整分类色，而不是误把该类别标记为错误。

## 5. 文字颜色与可读性

中性卡片正文采用 `#2B3137`，需要更柔和时统一采用 `#3F474E`；次级文字采用 `#626D76`，辅助信息采用 `#606D76`。语义卡片应先选择整张卡片的文字策略，而不是独立给每一行选色：

- **中性文字策略：** 标题与正文都采用协调的中性色，分类由填充、边框或色条承担。
- **主题文字策略：** 标题、正文、代码标识和辅助文字都使用该色系内足够深、接近中性的文字色；基础色谱中的“彩色文字”可同时用于标题与正文，核心卡片采用第 3.2 节的配套色组。
- 同一卡片默认只需一个主要文字色和一个略弱的辅助文字色，也可以全部使用同色。标题层级优先用字号、字重和间距建立，不依赖大幅改变明度或色相。
- 避免彩色标题搭配突兀的近黑正文；不要为了统一而把标题改成难读的浅色，或把整张图所有文字都强行染成蓝色。
- SVG、CSS 等实现优先使用组件级文字样式，例如 `.core-card text` 与 `.core-card .small`；检查辅助文字和代码字体规则的覆盖关系，防止正文落回全局近黑色或辅助文字落回不匹配的灰色。
- 错误、警告等有独立语义的短标签可以例外，但必须保持可读性，并有非颜色状态标记。

| 状态文字 | 颜色 |
|---|---|
| 当前 / 选中 / 聚焦 | `#4D6273` |
| 错误 | `#805F5F` |
| 警告 | `#766D56` |

- 普通文字与实际背景至少 4.5:1；大号文字至少 3:1。
- WCAG 大号文字通常至少为 18 pt，或 14 pt 粗体，不以图内相对大小判断。
- 默认不用纯黑正文；高对比度、打印或出版要求可以例外。
- 深色数据填充可使用白字，但要重新计算对比度。
- 透明、半透明、叠加或混合后的最终背景才是对比度计算依据。
- 不能用“弱化”“元数据”或“已消费”作为普通信息文字不满足对比度的理由。

## 6. 边框颜色

| 角色 | 颜色 |
|---|---|
| 普通边框 | `#CBD2D8` |
| 柔和边框 | `#D7DCE0` |
| 强边框 | `#A9B2BA` |
| 关键边界 | `#7C8791` |
| 当前 / 选中边框 | `#64798C` |
| 错误边框 | `#8A6666` |

分类卡片优先使用对应色系的柔和边框或图形强调色。柔和边框不是无障碍保证；必须辨认的非文本图形通常至少需要 3:1，按实际相邻颜色检查。不能只验证边框对白底，而忽略它与填充或相邻对象的关系。

## 7. 连接线、箭头与标签

| 关系 | 颜色 |
|---|---|
| 普通 | `#6D7881` |
| 弱 / 可选 | `#8B949C` |
| 上下文关系 | `#858F97` |
| 辅助线 | `#929AA1` |
| 当前 / 激活路径 | `#64798C` |
| 错误关系 | `#8A6666` |

- 普通关系线保持中性，不自动继承节点分类色。
- 线条本身表示数据系列或类别时可以采用分类色，同时提供标签、线型或标记。
- 弱线、上下文线和辅助线不保证在所有背景上达到必要对比度。若关系不可缺少，改用普通线色或更深颜色，通过位置、标签及适度视觉层级表达次要性；不能仅因次要就改用虚线。
- 当前路径结合线宽、标签或位置标记表达，不只改变为蓝色。
- 错误红只表示无效或失败关系，并附文字或错误标记。
- 箭头与对应连接线颜色一致；不同线型的含义保持一致。默认实线表示明确建模的关系，虚线表示可选或条件性关系，点线表示说明性关联；具体节奏、边框语义和路由遵循几何参考。
- 线条标签通常使用 `#626D76`；需要遮挡下方线条时使用与实际局部背景匹配的不透明填充，例如白底上的 `#FFFFFF` 或次级表面上的 `#F8FAFB`，不能任意覆盖成白块。

## 8. 当前、选中、聚焦与状态叠加

| 属性 | 颜色 |
|---|---|
| 可选状态填充 | `#F0F3F6` |
| 边框 / 外环 | `#64798C` |
| 文字 | `#4D6273` |
| 连接线 | `#64798C` |
| 局部强调 | `#5C7184` |

蓝色也可以表示普通主题，因此“变蓝”不是充分的状态标记。主题蓝填充 `#F1F4F6` 与状态填充 `#F0F3F6` 刻意接近，不能依靠二者的微小差异识别状态。

- 当前表示流程或数据中的当前位置；选中表示操作对象；聚焦表示键盘输入目标。
- 静态图只定义实际需要的状态；交互界面应区分三者，不把它们混为一个状态。
- 已有分类填充通常保留，通过加粗边框、独立外环、指针或文字表达状态。
- 只有相关路径进入当前状态，不把所有相连线条都改为蓝色。

叠加时分配独立视觉通道：

| 信息 | 默认通道 |
|---|---|
| 分类 / 主题 | 填充、标题或局部色条 |
| 错误 / 警告 | 标签、图标及状态边框 |
| 选中 / 聚焦 | 独立外环或选择标记 |
| 当前对象 / 路径 | 指针、线宽或“当前”标签 |

错误节点被选中时，保留错误边框与错误标签，另加蓝色外环。外环与边框之间留出可见间隔。若工具不支持外环，使用独立指针或明确标签，不直接覆盖错误状态。

## 9. 错误与无效状态

| 属性 | 颜色 |
|---|---|
| 填充 | `#F6F0F0` |
| 边框 | `#8A6666` |
| 文字 | `#805F5F` |
| 连接线 | `#8A6666` |

错误色用于失败、无效状态、损坏的引用、损坏状态或明确的破坏性操作与后果。不用于一般分类或装饰性强调。

过期引用不自动等于错误：尚可使用但需要注意时用警告；已失效或导致错误结果时才用错误。使用图标、标签或约定标记补充颜色。

## 10. 警告

| 属性 | 颜色 |
|---|---|
| 填充 | `#F7F4EC` |
| 柔和边框 | `#CFC5AA` |
| 文字 | `#766D56` |
| 连接线 / 强调描边 | `#8A816B` |

警告用于风险、待确认、接近阈值和仍可使用的过期信息。柔和边框不足以识别状态时使用强调描边，并检查背景对比度。

沙色、琥珀分类与警告很接近；共存时必须有警告图标或标签，必要时替换普通分类色。警告的视觉优先级由风险决定，不强制弱于普通选中状态。

## 11. 注释

| 类型 | 填充 | 边框 | 文字 |
|---|---|---|---|
| 普通 | `#FFFFFF` 或透明 | `#CBD2D8` | `#626D76` |
| 弱化 | 透明 | 无 | `#606D76` |
| 聚焦 | `#F0F3F6` | `#64798C` | `#4D6273` |

弱化注释依靠位置、间距和减少装饰降低视觉重量，不牺牲阅读。透明注释必须对实际背景检查。聚焦注释增加外环或明确标记，不能只靠蓝色与普通主题内容区分。

## 12. 内存、数组与单元格

| 状态 | 填充 | 附加表达 |
|---|---|---|
| 空 | `#FFFFFF` | 必要时标注“空” |
| 普通 | `#F3F5F6` | 清晰索引与边界 |
| 弱化 | `#ECEFF1` | 配合位置、减少强调或标签，不假设更深填充必然更弱 |
| 分类区域 | 对应分类浅填充 | 区域名称或范围标记 |
| 当前 | `#F0F3F6`，或保留分类填充 | 当前指针、粗边框或标签 |
| 已消费 | `#F3F5F6` | “已消费”标签、划线或约定标记 |
| 无效 | `#F6F0F0` | 错误描边及无效标记 |

| 边框状态 | 颜色 |
|---|---|
| 普通 | `#CBD2D8` |
| 必须辨认的单元格边界 | `#7C8791`，必要时进一步加深 |
| 当前 | `#64798C` |

地址、索引、偏移量与元数据：普通用 `#626D76`，辅助用 `#606D76`，当前用 `#4D6273`。这些是信息文字，不使用禁用文字色。

普通与已消费共享填充，但必须有非颜色差异。当前且无效时保留错误状态，使用外部指针或独立标签表示当前。

## 13. 背景与颜色面积

大型画布、嵌套容器和子系统区域通常保持中性，即使它们属于同一类别。通过标题、边界或局部色条表达分类，不默认整页染色。

正常状态示意图可参考原有视觉比例：

| 类别 | 参考占比 |
|---|---:|
| 白色与中性表面 | 75-85% |
| 分类浅填充 | 10-20% |
| 当前 / 聚焦强调 | 3-5% |
| 警告 / 错误 | 小于 2% |

这些区间不是必须相加为 100% 的面积预算，也不是加入颜色的最低配额。主题蓝浅填充计入分类填充，而非当前状态。数据图、故障分析图和风险图可明显偏离；不能为了符合比例隐藏必要信息。

## 14. 统计图表与同色系序列

组件用色与数据编码用途不同，不能把很浅的卡片色直接用于重要细线。

- 单一数据系列优先使用一个主色。
- 有序数量或强度使用明度有序的色阶；无序类别不能只用深浅暗示不存在的等级。
- 多条曲线优先使用足够深的图形色或彩色文字色，配合线型、标记与直接标签。
- 围绕基准的正负偏差使用有中性中点的发散色板。
- 连续定量色图应选用经过验证、感知变化合适的色图；允许有数据含义的渐变，不允许装饰性渐变。

需要离散蓝色等级时，可从下表选择 3-4 级，而不是强制全部使用：

## 15. 验证与例外

将可读性与视觉层级作为两项独立验收：对比度合格不代表主题核心突出，配色协调也不代表文字可读。

交付时使用 [统一验收清单](../SKILL.md#输出与验收)，不另设重复检查项。色值、实际背景上的对比度、父子容器层级及状态叠加的判定依据为本参考对应章节。

规则默认禁止霓虹色、高饱和度分类拼盘、装饰性渐变、大面积鲜艳子系统背景、每对象独立分色、装饰性错误红以及仅靠颜色传递信息。

高对比度模式、打印、出版要求、领域标准或数据语义可以覆盖风格偏好，但不能覆盖信息真实性与可读性。例外应说明原因；未经实际验证，不宣称已经通过渲染、色觉模拟或打印检查。

## 16. 核心规则

**中性表面建立结构，蓝色默认建立主题。**

**同色系组织层级，协调色系区分类别，不预设固定颜色组合。**

**浅色承载区域，深色承载文字、关键数据与重点。**

**填充主要表达主题或分组，边框、线型和独立标记共同表达状态。**

**色谱提供可用颜色，原则决定如何组合，可读性决定是否合格。**
