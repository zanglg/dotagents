# 技术图表配色与视觉规范

## 目标

在保留具体色谱与组件规则的基础上，形成克制、协调、清晰的技术图表。默认用于浅色背景；深色主题不直接反转本色板，需要重新设计和验证。

- 中性色建立结构，蓝色默认建立主题。
- 分类浅填充与主题核心填充分开设计；核心对象不得融入父容器背景。
- 浅色承载区域，较深颜色承载文字、线条和重点；同一卡片的文字保持色调一致，标题优先用字号和字重建立层级。
- 优先使用同色系层级；必要时增加协调色系，不限定蓝紫红或其他固定组合。
- 同等类别保持相近视觉重量，只有明确的重点才额外突出。
- 同角色的线宽、圆角、箭头、字体和间距保持一致，按最终显示尺寸校准。
- 布线路径与线型语义分开；双向连线尽量平行、对称且视觉权重一致。
- 可读性、信息真实性和状态辨识优先于风格偏好。

## 使用流程

1. **识别信息与输出条件。** 确定图表类型、主要内容、分类、顺序、数值、关系和状态；确认最终尺寸、背景、屏幕或打印用途。默认优先整合为一张图，先优化布局、分组和局部细节，仅在仍无法清晰呈现时拆分；不以过度缩小文字或省略关键关系强行合图。用户没有额外要求时，采用白底、深中性文字和蓝色主色，不为非必要选项反复提问。
2. **读取适用规范。** 应用颜色前阅读 [配色规范与色值](references/palette.md)；创建图形或调整几何、排版及连线前阅读 [几何、排版与连线规范](references/visual-style.md)。完整绘图需阅读两者，不以笼统的“低饱和度风格”代替具体色值、尺寸和语义映射。
3. **选择最小够用的组合。** 先考虑中性色加一个主色，再考虑同色系层级；无序类别难以区分时增加色相，而不是强行只用深浅。原色库是候选库，不要求全部使用，也不要求总从蓝色扩展到某几种固定颜色。
4. **分配语义角色。** 先指定画布、父容器、分类浅填充、主题核心填充、描边、关系线和状态标记。为每张卡片配套指定标题、正文及辅助文字，不能只改标题颜色而让正文回落到近黑默认值。映射到绘图工具的组件级样式、变量或类，记录类别映射，并在同图及连续图示中保持一致。
5. **统一几何与布线。** 在最终尺寸下应用角色级线宽、圆角、字体、间距和箭头规格。先声明实线、虚线、点线及边框含义，再按 `straight → polyline → orthogonal → curved` 布线。同组件对的双向连接作为一组设计，优先使用分离、平行、对齐端口的通道，不各自随意改变角度或样式。
6. **处理状态叠加。** 分类通常使用填充或标题；错误与警告使用标签、图标及状态边框；选中或聚焦使用独立外环或标记。主题蓝不等于选中；错误且选中的对象必须同时呈现两种信息。错误也不自动改变关系线型，以免把“失败”误编码为“可选”。
7. **验证并修正。** 分别检查可读性与视觉层级：前者验证实际前景与背景对比度，后者在真实父容器背景及最终尺寸下确认主题核心突出、卡片文字色调统一、相邻类别可辨。文字对比度达标不代表视觉层级合格，也不要求所有背景之间达到 3:1。检查灰度及色觉缺陷辨识，并检查线型含义、成对布线、箭头和标签碰撞；不能为了协调而模糊信息。

## 选色决策

| 信息 | 默认策略 |
|---|---|
| 单一主题、核心对象 | 中性色加蓝色；明确的主题或领域惯例可替换主色 |
| 同一类别内部层级 | 同色系的浅填充、较深描边和深色文字 |
| 有序数值或强度 | 明度有序的单色或协调多色序列 |
| 无序类别 | 视觉重量相近、可区分的分类色，配合标签或图例 |
| 围绕基准的正负偏差 | 有中性中点的发散色板，不硬套单向蓝色序列 |
| 多条曲线 | 足够深的线色，结合线型、标记或直接标注 |
| 当前、选中、错误、警告 | 颜色与独立状态标记共同编码 |

## 必须遵守

- 大部分结构表面保持白色或接近中性；避免鲜艳的大面积子系统背景。
- 普通关系线不自动继承节点分类色；线条本身承载类别或数据系列时例外。
- 默认实线表示明确建模的关系，虚线表示可选或条件性关系，点线表示说明性关联；卡片及分组边框同样要有明确含义。领域标准或统计数据系列可覆盖默认映射，但须说明。
- 不因反向、次要、绕行或装饰需要而改用虚线或点线。布线回退顺序是直连、简单折线、正交折线、曲线；同组件对的连线协调选择路径。仅为整齐、对称或垂直接入卡片，不足以改用折线；直线无碰撞且方向清晰时，应保留直线。
- 独立请求与响应使用两条平行单向线；只有无需区分方向行为的对称关系才用一条双头线。
- 不为每个对象分配不同颜色，不将颜色作为唯一的信息通道。
- 不使用装饰性渐变、霓虹色或无意义的强色相对撞。连续数值色图可使用经过验证的渐变。
- 默认不用纯黑正文；高对比度、打印或出版要求可以例外。
- 错误红只用于真实错误、无效、失败或明确破坏性状态，不用于装饰。
- 普通文字对比度至少 4.5:1；大号文字至少 3:1。必要的非文本图形通常至少 3:1，按实际相邻颜色检查。
- 不把“禁用文字”用于仍需阅读的索引、注释、历史数据或已消费状态；不通过整体降低透明度来弱化含文字对象。
- 不声称已做未实际执行的渲染、打印、色觉模拟或对比度检查。

## 输出与验收

绘图任务应把颜色、几何参数及语义映射落实到最终图形或源代码中，不只给出风格建议。咨询可以输出角色、色值、尺寸、线型和图例；审查任务应指出具体对象、问题组合和替代方案。

以下为统一交付检查清单；两份参考文件提供判定依据，不再重复列项。按任务检查适用项，不适用或未验证的项目如实标明，不勾选为通过。

- [ ] **配色用途：** 落实了具体色值并保留中性、轻盈基调；新增颜色有信息用途，未将示例组合当作固定要求。
- [ ] **视觉层级：** 同等类别视觉重量相近；核心对象与实际父容器明显区分，不比普通白色卡片更容易融入背景。
- [ ] **卡片文字：** 标题、正文及辅助文字色调协调，没有彩色标题与突兀近黑正文的无意混用。
- [ ] **对比度：** 文字、必要边界、箭头及线条对实际相邻颜色达标；透明导出已明确最终背景，改变填充后已重新验证文字色组。
- [ ] **语义与状态：** 主题色、类别及状态不混淆，叠加状态不丢失；同图及系列图示的映射与图例一致。
- [ ] **尺寸与规格：** 已在最终显示或刊载尺寸下检查清晰度；同角色及系列图示的线宽、箭头、圆角、字体、间距和虚线节奏一致。
- [ ] **路由必要性：** 已逐条确认折线或曲线确有必要；尝试直连并调整标签后，仍无法采用更简单路径，且有避障、端口或领域约束等具体依据，并按规定顺序回退。
- [ ] **成对连线：** 同组件对的多条线尽量平行、对称且可独立追踪；偏离有具体原因，请求与响应等独立关系未被误合并为双头箭头。
- [ ] **线型与边框：** 实线、虚线、点线及卡片 / 分组边框各有明确含义，不用于装饰或任意弱化。
- [ ] **端点与碰撞：** 箭头方向、端点及连接圆点准确，交叉不被误认为连接；标签不碰撞对象、箭头或相邻通道，标签底色与局部背景匹配。
- [ ] **非颜色辨识：** 浅填充或色相不是唯一分类依据；灰度及常见色觉缺陷条件下，仍可通过标签、线型、形状或位置理解信息。
- [ ] **例外与验证记录：** 已说明领域标准、数据编码等例外，以及尚未验证的渲染、打印、色觉模拟或其他输出条件；未将遵循规范等同于通过实际检查。
