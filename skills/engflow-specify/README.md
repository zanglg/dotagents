# Engflow Specify

[SKILL.md](SKILL.md) is the authoritative contract.

Specify creates, revises or previews a testable description of intended
behavior. The [specification change method](references/specification-core.md)
updates the smallest complete set of affected requirements and acceptance.
Specify can investigate a source fact or ask a follow-up in the same task;
no prior Clarify call, report or handoff is required. Exploratory discussion or
correction of an interpretation does not add write authority; a clear scoped
change request does not need repeated confirmation. Material changes receive a
proportionate check and targeted re-check after corrections. Disclose self-checks
rather than claiming independent review. Design owns technical solution selection.

Examples:
- "Turn this discussion into a Spec preview."
- "Update the Spec with these decisions and preserve existing IDs."

Reuse the selected feature and project conventions. The
[Spec outline](assets/spec.md) is optional. A saved Spec does not authorize
design, implementation or downstream changes.
