# Engflow Specify

User guide; [SKILL.md](SKILL.md) is the authoritative agent contract.

## Purpose

Synthesize discussion and evidence into behavioral requirements, scope and
observable acceptance; resolve ordinary clarification within the same task.

## Examples

- "Turn these decisions into a Spec preview; write nothing."
- "Update the agreed Spec, preserving IDs and deferred scope."

## Inputs and outputs

Provide decisions, constraints and a target or preview request. Receive a Spec
or preview with acceptance, unknowns and source-update limits. Supplied/project
paths win; otherwise use specs/NNN-short-name/spec.md. The
[outline](assets/spec.md) is optional.

## Installation and collaboration

Install all sibling `engflow-*` folders together, preserving references.
Invoke explicitly; see the [group guide](../../docs/engflow/README.md) for composition.

## Validation and references

Check requirement-to-acceptance traceability, stable IDs, preview boundaries and
preservation of effective decisions. Saving a Spec does not authorize implementation.
