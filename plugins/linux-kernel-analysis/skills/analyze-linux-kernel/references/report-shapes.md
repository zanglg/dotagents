# Report Shapes

## Contents

- Focused answer
- Subsystem learning document
- Investigation handoff

## Focused answer

Use for one operation or one disputed claim:

1. Baseline and conclusion
2. Short source path
3. One diagram or table if needed
4. Evidence anchors
5. Conditions and unresolved questions

## Subsystem learning document

Use for broad understanding:

1. Problem, goal, and external contract
2. Boundary and architecture
3. Core objects and relationships
4. Ordinary operation journey
5. State and path selection
6. Execution-context handoffs
7. Lifetime, ownership, and concurrency
8. Resources and backpressure
9. Completion, failure, and recovery
10. Performance model
11. Architecture and platform differences
12. Validation plan and unknowns

Prefer these high-value visuals when the source supports them:

- architecture boundary graph;
- object relationship/lifetime graph;
- path-selection or state graph;
- context handoff graph.

## Investigation handoff

Use when analysis cannot be completed in the current environment:

```text
Established facts:
Open claim:
Why unresolved:
Required source/configuration/runtime data:
Smallest next experiment:
Expected observations:
How each observation changes the conclusion:
```
